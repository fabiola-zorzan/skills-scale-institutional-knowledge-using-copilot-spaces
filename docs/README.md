# OctoAcme Project Management Docs

Welcome to the OctoAcme Project Management documentation hub. This README provides a summary of the key project management practices we use and links to detailed guides.

## Summary of Project Management Processes

At OctoAcme, we follow a structured yet flexible approach to project management that emphasizes customer value, iterative delivery, and evidence-based decision-making. Our processes are designed to ensure alignment, clarity, and continuous improvement across all projects.

### Core Principles

- **Customer-first:** Prioritize user value and usability in projects. Every decision is evaluated through the lens of customer impact and satisfaction.
- **Iterative delivery:** Work is delivered in small, testable increments to enable rapid feedback and improvement. This allows us to validate assumptions early and adjust course as needed.
- **Clear ownership:** Each project has a named Project Manager and Product Lead. Clear ownership ensures accountability and streamlined decision-making.
- **Evidence-based decisions:** Success and improvements are measured using defined metrics and retrospectives. We make decisions based on data and learnings from past experiences.
- **Consistent documentation:** Artifacts such as one-pagers, risk registers, and retrospectives are kept up-to-date in this repository. Documentation serves as the single source of truth for our processes.
